指点江山 · 情境式指令提示   v4.12   安装使用说明
============================================================

一、交付文件
  指点江山_Setup_4.12.exe    单文件安装程序（推荐：拷到另一台电脑双击即可）
  指点江山_绿色版_4.12.zip   免安装备用版（解压后双击 指点江山.exe 直接运行）
  SHA256.txt                文件校验值，用于确认传输过程中没有损坏

二、运行环境
  Windows 10 / 11，64 位。
  目标电脑不需要装 Python、不需要装任何运行库、不需要联网、不需要管理员权限。
  默认安装到当前用户的 %LOCALAPPDATA%\Programs\指点江山，只对当前 Windows 账户生效。
  32 位系统不支持（如需 32 位版本请单独说明）。

三、安装步骤
  1. 把 指点江山_Setup_4.12.exe 复制到另一台电脑（U 盘 / 微信 / 网盘均可）。
  2. 双击运行。单文件包首次启动需要 3~5 秒解压，稍等一下向导窗口才会出现。
  3. 如果出现蓝色的「Windows 已保护你的电脑」：
     点「更多信息」→「仍要运行」。
     这是因为程序没有购买商业代码签名证书，首次运行必现，属正常现象。
  4. 安装位置可自定义：在输入框直接改，或点「浏览…」选任意目录；
     按需勾选开机自启 / 桌面快捷方式，点「立即安装」。
  5. 安装完成后程序自动驻留系统托盘，按住 Ctrl 即可看到虚拟键盘。

  静默安装（批量部署可选）：
     指点江山_Setup_4.12.exe --silent --dir "D:\指点江山"
  可附加：--no-launch（装完不启动）、--no-autostart、--no-desktop、--no-kill

四、怎么用
  按住 Ctrl / Shift / Alt / Win（也支持 Ctrl+Shift 这类组合）
      → 屏幕浮出半透明虚拟键盘，能用的组合键亮起并显示图标 + 功能文字。
      默认停靠屏幕顶部、悬浮紧凑键盘。
  松开辅助键 → 按设定延时消失（默认立即）。

  应用情境感知：面板识别当前前台窗口，同一个 Ctrl+B 在 WPS 文字里是「加粗」、
  在浏览器里是「加粗」、在 PS 里变成对应的设计快捷键。未收录的软件退回通用指令表。

  常用热键：
      Ctrl+Esc        开启 / 关闭「按住辅助键自动弹出键盘」（已拦截开始菜单）
      Ctrl+Alt+H      锁定 / 解锁键盘常驻
      Esc             立即收起
      Ctrl+Alt+M      切换键帽可点 / 穿透
      Ctrl+Alt+O      打开独立透明度滑块窗口

  右上角悬浮功能条永远可点击、鼠标不会穿透：
      我的快捷键   左键开 / 关自定义面板；右键弹出面板管理（详见第五节）
      符号页       打开 166 个上 / 下标 + 136 个常用特殊符号；点一下直接输入到光标处
      键帽可点     开启后可用鼠标点虚拟键帽；关闭则鼠标穿透
      半透明       半透明总开关
      延时消失     点一下循环切换 关 / 5 秒 / 10 秒
      透明度       拖动滑杆实时调整（10%~100%）

  设置（托盘右键 → 设置）：主题、壁纸联动、行为四项、弹出快捷键、布局、
  停靠位置、键盘缩放 / 字体大小（均为 50%~200%，默认 100%）、指令显示等，
  全部用滑杆和按钮操作，不需要手填数字或改配置文件。

五、自定义快捷键面板（v4.11 / v4.12 重点功能）

  1. 开关（键盘上方功能条最左「我的快捷键」按钮）
       左键点一下   → 开启：整块键盘变全灰，不显示任何内置快捷键，
                      所有键位都等你自行定义。
       再左键点一下 → 关闭：立即恢复常用快捷键面板。
       右键点一下   → 弹出「自定义快捷键面板」管理器：可新建 / 重命名 / 删除
                      多套面板，指定当前使用哪一套。

  2. 给一个键设置快捷键
       先左键开启「我的快捷键」（键盘全灰），在任意键帽上右键 →
       选「自定义设置此键…」，填三项：
         组合键  勾选 Ctrl / Shift / Alt / Win + 填主键（如勾 Ctrl、主键填 V，
                 即 Ctrl+V）—— 这是点击键帽时【实际发送给系统的按键】。
         名称    印在键帽上的文字标签（只是给你看）。
         作用    鼠标悬停时显示在键盘底部的一行说明（只是提示）。
       保存后该键高亮显示名称，点它就发送所配的组合键。

       例：想让点 C 键执行粘贴 —— 右键 C 键，勾 Ctrl、主键填 V（组合键 Ctrl+V），
       名称填「粘贴」。名称写什么不影响结果，决定动作的是组合键。

  3. 会不会和原有快捷键冲突？不会。
       · 自定义开启后，内置指令表整个清空（键盘全灰），只显示你设置过的键，
         不存在两套快捷键同时生效。
       · 点击前会先释放左手按住的物理 Ctrl，再干净地发送所配组合键，
         不会叠加成双 Ctrl，也不会被 WPS 误判成别的快捷键。
       · 名称写「粘贴」而组合键是 Ctrl+C，执行的是复制 —— 名称不参与执行。
         真正发出的是组合键，最终由目标软件（记事本 / WPS / Word / PS…）解释，
         效果和你在键盘上按同样物理组合键完全一样。

       一句话：组合键才是动作，名称只是标签。

  4. 配置保存在哪里
       %APPDATA%\指点江山\config.json 的 custom_panels（多套面板及每个键的
       combo / name / action），active_custom_panel 是当前面板序号，
       custom_active 是开关状态。日常用 GUI 操作即可，无需手改此文件。

六、开机自启与卸载
  开机自启在安装时勾选即可，也可在托盘菜单里调整。
  卸载（三种方式任选）：
     1. Windows「设置 → 应用 → 应用和功能」里找到 指点江山，点卸载；
     2. 开始菜单 → 指点江山 → 卸载 指点江山；
     3. 安装目录里的 Uninstall.exe。
  卸载默认保留个人设置（透明度、延时、键盘位置、自定义面板等），
  以后重装会继续生效；勾选「同时删除我的个人设置」可彻底清除。

七、文件位置
  程序    %LOCALAPPDATA%\Programs\指点江山
  配置    %APPDATA%\指点江山\config.json
  日志    %TEMP%\keyhint_setup.log（仅静默安装时生成）

八、常见问题
  Q：杀毒软件报毒 / 拦截？
  A：PyInstaller 打包的未签名程序常被启发式引擎误报。本程序不含联网、自复制、
     提权行为，全部源码可查。请添加信任，或改用绿色版并自行排除目录。

  Q：另一台电脑双击没反应？
  A：确认是 64 位 Win10/11；检查是否被 SmartScreen 或杀软拦截；
     可尝试右键「以管理员身份运行」一次，或查看 %TEMP%\keyhint_setup.log。

  Q：按住 Ctrl 没出现键盘？
  A：先按 Ctrl+Esc 确认「按住辅助键弹出虚拟键盘」处于开启状态；
     再看托盘区是否有 指点江山 图标（可能折叠在「^」里），右键确认「启用」已勾选。

  Q：自定义面板点键帽没反应？
  A：确认「我的快捷键」处于开启状态（按钮高亮、键盘全灰）；该键是否右键设置过组合键；
     灰键（没设置过的键）在自定义模式下不执行任何动作，需先右键设置。

  Q：笔记本外接了多个显示器？
  A：虚拟键盘默认停靠在主屏顶部，可在设置里改位置或拖顶栏自定义。
