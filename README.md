# KeyHint · 情境式指令提示（PC 移植版）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE) [![Platform: Windows](https://img.shields.io/badge/Platform-Windows-blue.svg)](https://www.microsoft.com/windows) [![Release](https://img.shields.io/badge/Release-v4.07-green.svg)](https://github.com/dicky4x/KeyHint/releases/latest)

把 HUAWEI MateBook Fold 非凡大师虚拟键盘上那个「长按 Ctrl，C 键亮起并显示『复制』」的功能，搬到普通 Windows 电脑上。

> **不想自己构建？** 直接到 [Releases 页面](https://github.com/dicky4x/KeyHint/releases/latest) 下载 `KeyHint_Setup_4.07.exe`（图形化安装包，17 MB）或 `KeyHint_绿色版_4.07.zip`（免安装），双击即可用。仓库只存放源码，构建产物统一放在 Releases。

这是一个**常驻系统托盘的小插件**：按住 `Ctrl` / `Shift` / `Alt` / `Win`（或它们的双键组合），屏幕浮出**半透明全尺寸虚拟键盘**，所有能与之匹配的组合键**同时亮起**，显示「图标 + 功能文字」；**松开辅助键后按你设定的延时消失**（默认立即），穿透模式下鼠标完全穿透，不挡住后面的文字和文件。

> 本项目为个人开源移植实现，与华为公司无任何关联，不使用华为内部代码或资源。

**v4.07（当前）：常驻任务栏 + 开机自启动，托盘菜单可勾选**。托盘右键最上方新增两个勾选项——「常驻任务栏（任务栏图标 + 托盘锁定显示）」和「开机自启动」，均默认开启。勾选常驻后：任务栏出现一个 KeyHint 按钮（点击弹出同款菜单），托盘图标定期保活刷新、不被资源管理器折叠隐藏。主程序图标也已在 v4.07 换成深空灰简约矢量键盘（多尺寸 `.ico`）。v4.06 的开关提示胶囊、v4.05 的异步弹出 + 后台预热、v4.04 的两态统一与流畅优化全部保留。

![v4.06 效果预览](v4.06_效果预览.png)

> 默认「松手即隐」时想拖动键盘：左手按住 Ctrl、右手拖，或先在右上角控件条把「延时消失」设成 5 秒。

**v4：消失时机由你决定**。v3 里「键帽可点」一开就强制粘滞到按 `Esc`，对左手按 Ctrl、右手点鼠标的用法是多余的，这个约束已整个去掉。虚拟键盘**右上角**的控件条新增「延时消失」档位：

| 控件 | 作用 |
|---|---|
| 「键帽可点」拨动开关 | **关（默认）**＝鼠标穿透；**开**＝键帽可用鼠标点击（等同按下物理组合键）。**不再影响何时消失** |
| 「半透明」复选框 | 取消勾选 → 100% 完全不透明 |
| **「延时消失」胶囊（v4）** | 点击循环「关（松手即隐）→ 5s → 10s」；也会显示设置里自定义的秒数 |
| 透明度滑杆 | 10%~100% 连续可调，拖动时键盘**实时**变浓淡 |

两种模式统一走同一个 `hide_delay_ms` 倒计时：默认 `0`（松手即隐），设 5 秒 / 10 秒就晚 5 / 10 秒收起；**延时期间点键帽或拖控件条都会重新计时**，`Esc` 随时立即收起，锁定态（`Ctrl+Alt+H`）不受影响。托盘「松手后延时消失」里另有 3 / 15 / 30 秒档和自定义秒数输入框（支持 `2.5` 这类小数），也可直接改 `config.json`。

## 一、快速开始

**环境**：Windows 10/11，Python 3.8+，Pillow（唯一第三方依赖）

```bash
pip install pillow
```

| 操作 | 方式 |
|---|---|
| 启动（无黑窗，推荐） | 双击 `启动 KeyHint.vbs` |
| 启动（可看日志/排错） | 双击 `启动（调试）.bat`，或命令行 `python app.py` |
| 只看效果不挂钩子 | `python app.py --demo --seconds 10` |
| 退出 | 右下角托盘图标 → 右键 → 退出 |

启动后托盘出现蓝色键盘图标。**按住 Ctrl 约 0.15 秒**即可看到面板，**松开立即消失**（默认档）；想改成延时消失，或点键帽、调透明度，直接操作键盘右上角的控件条。右键托盘图标打开全部设置（备用入口）。

`启动 KeyHint.vbs` 会自动探测几个 Python 安装路径，挑一个**确实装了 Pillow** 的解释器再用 `pythonw` 静默启动（Windows 图形界面与终端的 PATH 可能不同，直接写 `pythonw.exe` 有时会挑到没装依赖的那个）；都不可用时会弹窗提示 `pip install pillow`。

> 若要开机自启：按 `Win+R` 输入 `shell:startup`，把 `启动 KeyHint.vbs` 的快捷方式放进去。

### 安装版（可选）

双击 `安装包/KeyHint_Setup_4.07.exe` 启动图形化安装向导，**无需管理员权限**：

- **安装位置可自定义**：向导中间的「安装位置」输入框可以直接修改，点「浏览…」选择任意目录；命令行也支持 `KeyHint_Setup_4.07.exe --silent --dir "D:\Tools\KeyHint"`。安装器会先检查目录是否可写，失败会明确提示换位置。
- 可勾选开机自启、创建桌面快捷方式、装完立即运行；卸载入口与快捷方式会跟着自定义目录正确生成。
- 卸载：开始菜单「卸载 KeyHint」，或运行安装目录下的 `Uninstall.exe`。个人设置默认保留，勾选「同时删除我的个人设置」才会清除。
- 卸载项只写 `HKCU`，可在「设置 → 应用」里管理；全程不需要 UAC 提权。

> 预编译安装包与绿色版请到 [Releases](https://github.com/dicky4x/KeyHint/releases/latest) 下载；本仓库按 `.gitignore` 规则不收录构建产物，需要自己构建时见文末「本地构建」。

## 二、怎么用

| 你按下的键 | 屏幕显示 |
|---|---|
| 按住 `Ctrl` | 74 组 Ctrl 指令，C=复制、V=粘贴、S=保存、A=全选…… |
| 按住 `Ctrl+Shift` | 实时切换为双组合指令，V=无格式粘贴、T=恢复标签页、ESC=任务管理器…… |
| 按住 `Shift` | 数字键显示 `!@#$…`、方向键显示「选择」、Delete 显示「永久删除」 |
| 按住 `Alt` / `Win` | Alt+Tab 切换窗口、Win+D 显示桌面、Win+方向键贴靠窗口…… |
| 按住 `Ctrl+Alt` / `Win+Shift` / `Alt+Shift` / `Win+Ctrl` | 对应的完整双组合指令表 |
| 按任意组合键（如 Ctrl+C） | 对应键帽闪光确认，键盘保持显示，方便连续查看 |
| `Ctrl+Alt+H` | 锁定 / 解锁速查面板（锁定后不随松键消失） |
| `Esc` | 立即收起延时中 / 停留中 / 锁定的面板 |
| 托盘图标双击 | 锁定 / 解锁 |
| **点右上角「键帽可点」** | 切换点击 / 穿透（不影响消失时机） |
| **点右上角「延时消失」** | 循环 立即 → 5s → 10s |
| **拖右上角滑杆** | 实时调节透明度 |

**应用情境感知**：面板会识别前台进程，同一个 `Ctrl+D` 在 Word 里显示「字体设置」、在浏览器里显示「添加书签」、在资源管理器里显示「添加到收藏」。内置 9 类情境：浏览器、Word/WPS 文字、Excel/WPS 表格、PPT、VS Code/IDE、资源管理器、微信/钉钉/飞书、PS/剪映、终端，未命中时用「通用」指令表。

### 热键（备用入口）

| 热键 | 作用 |
|---|---|
| **`Ctrl+Esc`（v4.01）** | **开关「按住辅助键自动弹出虚拟键盘」**；已拦截开始菜单。托盘可改为 `Ctrl+Alt+P` / `Ctrl+Alt+K` / 自定义 |
| `Ctrl+Alt+M` | 切换「键帽可点 / 鼠标穿透」，等价于右上角的拨动开关 |
| `Ctrl+Alt+O` | 打开独立透明度滑块窗口 |
| `Ctrl+Alt+H` | 锁定 / 解锁速查面板 |
| `Esc` | 收起停留中的 / 锁定的面板 |

## 三、右上角控件条与延时消失（v4）

### 3.1 出现 / 消失规则

| 延时档位 | 按住 Ctrl | 松开 Ctrl |
|---|---|---|
| **关（`0`，默认）** | 键盘 + 右上角控件条一起出现 | **立即全部消失**，两种点击模式都一样 |
| **5 秒 / 10 秒** | 同上 | 面板保留到倒计时结束；期间可用鼠标点键帽、拖滑杆、点延时档位 |
| **锁定态（`Ctrl+Alt+H`）** | 同上 | 常驻，不受延时影响，再按一次热键或 `Esc` 收起 |

穿透 / 点击两种模式**不再有区别对待**：都走同一个 `hide_delay_ms` 倒计时。倒计时期间任何交互都会**重新计时**，因此不会出现「拖滑杆拖到一半键盘没了」；`Esc` 随时立即收起。延时结束后面板自动隐藏，下层文字、文件照常点选。

> v3 曾假设「手要从 Ctrl 移到鼠标，所以点击模式必须粘滞到 Esc」。左手按 Ctrl、右手握鼠标时这个假设不成立，v4 改为纯倒计时，由用户自己决定留多久。旧版想要的效果仍可得到：把延时设成 30 秒或自定义更长即可。

### 3.2 控件条为什么永远点得到

`WS_EX_TRANSPARENT` 是**整个窗口**级样式，同一个窗口做不到「右上角可点、其余穿透」。因此拆成两个分层窗口：

| 窗口 | 样式 | 行为 |
|---|---|---|
| 键盘主体 | `WS_EX_LAYERED` + 动态增删 `WS_EX_TRANSPARENT` | 穿透或可点击键帽，随开关切换 |
| 右上角控件条 | `WS_EX_LAYERED`，**永不**加 `WS_EX_TRANSPARENT` | 永远可点；控件以外的透明区仍由 alpha 自动穿透 |

控件条带约 636×44 像素的底板（v4 因新增延时档位而加宽），这一小块**不穿透**是「永远可点击」的必要代价；键盘其余区域的穿透不受影响。两个窗口都带 `WS_EX_NOACTIVATE`，点控件不会抢走前台窗口，应用情境感知不会跑偏。

### 3.3 操作宽限

拖滑杆 / 点开关时手可能要离开 Ctrl。因此**正在操作控件条时**（鼠标按下或拖动中，以及刚点完的 1.5 秒）面板至少保留 `ui_grace_ms` 毫秒，且不会打断拖动；这个宽限与 `hide_delay_ms` 取**较大值**。纯看图且延时为 0 时仍是松手即隐。

### 3.4 滚轮

滚轮**不再调节透明度**，只用滑杆或托盘菜单调。点击模式下覆盖层收到的滚轮消息会转发给下层应用正常滚动；穿透模式下本来就收不到，行为与没有覆盖层时一致。

### 3.5 点击键帽能做什么

- 悬停键帽出现白色可点击外框、光标变手型；**灰键也能点**。
- 点高亮键 → 注入「当前组合 + 该键」。面板是 `Ctrl` 时点 C 键就等于按下 `Ctrl+C`。用 `SendInput` 注入，事件带专用标记，不会被本程序自己的全局钩子误判成「用户按住了 Ctrl」。
- 点 `Ctrl` / `Shift` / `Alt` / `Win` 键帽 → 切换虚拟按住的辅助键，面板实时升级成 `Ctrl+Shift` 等组合，纯用鼠标也能浏览全部组合指令。
- 覆盖层上点右键 = 弹出托盘同款菜单。

> 点击含 `Win` 的组合时 Windows 自身会弹出开始菜单，属系统行为。

### 3.6 备用入口（托盘）

| 操作 | 效果 |
|---|---|
| 托盘 ☑ **半透明显示（可调）** | 总开关；取消勾选 → 100% 不透明 |
| 托盘 **透明度调节…** | 独立原生滑块窗口（10%~100%），键盘保持显示以实时预览 |
| 托盘 → 外观主题 → 透明度 | 5 个档位 +「更浓 / 更淡 ±5%」 |
| 托盘 → **松手后延时消失** | 立即 / 3 / 5 / 10 / 15 / 30 秒 + **自定义秒数…**（支持 `2.5` 这类小数，范围 0~600 秒） |
| 托盘 → 鼠标点击选项 | 同一个点击开关、执行后保持面板 |

三处（控件条胶囊、托盘菜单、`config.json` 的 `hide_delay_ms`）状态同步；改完即时生效并写盘。

自检：`python selftest_v4.py`（需用装了 Pillow 的解释器），七个阶段验证：点击模式 + 0 延时仍松手即隐、档位循环写盘、5 秒倒计时到点消失、延时期间点键帽注入并重新计时、Esc 立即收起、自定义秒数窗口与解析边界、滑杆/滚轮/半透明开关回归。`selftest.py` 为基础链路回归；`selftest_v2.py` / `selftest_v3.py` 是对应旧版本语义的历史自检，已归档不再作为当前版本的判据。

## 五、设置项

日常操作都在**键盘右上角控件条**上完成；托盘菜单作为备用入口，分组如下：

| 分组 | 选项 |
|---|---|
| 顶层开关 | 启用情境式指令提示、**鼠标可点击键帽（关闭＝穿透）**、**半透明显示（可调）**、锁定速查面板 |
| **松手后延时消失** | 立即 / 3 / 5 / 10 / 15 / 30 秒、**自定义秒数…**（0~600 秒，支持小数）；控件条胶囊为 立即→5s→10s 快捷循环 |
| 透明度调节 | 独立滑块窗口（实时预览）、更浓 / 更淡 ±5%、100 / 92 / 78 / 60 / 40% 档位 |
| 鼠标点击选项 | 允许点击键帽、执行后保持面板 |
| 键盘规格 | 悬浮紧凑 / 全尺寸 104 键、窄距键帽、停靠底部 / 屏幕居中、**键盘缩放 80/100/125/150%**、**重置大小与位置** |
| 指令显示 | 图标+文字 / 纯文本、应用情境感知、输入语言键帽、按键反馈音 |
| 触发的辅助键 | 单独开关 Ctrl / Shift / Alt / Win；唤起延迟 0 / 150 / 300 / 500 ms |
| 外观主题 | 深色 / 浅色 / 跟随系统、壁纸联动强调色 |

所有设置即时生效并写入 `config.json`。也可直接编辑该文件后点「重新加载配置」。开关相关配置键：

| 键 | 默认值 | 含义 |
|---|---|---|
| `fade` | `true` | 半透明总开关；`false` = 强制 100% 不透明 |
| `opacity` | `80` | 透明度百分比，右上角滑杆可调 10~100 |
| `mouse_click` | `false` | `true` = 键帽可点击；`false` = 鼠标穿透。**与何时消失无关** |
| `hide_delay_ms` | `0` | **v4 核心开关**：松辅助键后延时多少毫秒消失。`0`=立即；`5000`=5 秒；`10000`=10 秒；也接受 `2500` 这类自定义值（上限 600000） |
| `click_keep` | `true` | 点击键帽后是否保持面板（保持＝隐藏倒计时重新计时） |
| `ui_grace_ms` | `1500` | 操作右上角控件时的最短保留时间（毫秒）；与 `hide_delay_ms` 取较大值 |
| `popup_enabled` | `true` | **v4.01**：`false` = 按住辅助键不再自动弹出；仍可用 `Ctrl+Alt+H` 手动打开 |
| `toggle_hotkey` | `Ctrl+Esc` | **v4.01**：弹出开关的组合键，可填 `Ctrl+Alt+P` 等「修饰键+普通键」 |
| `kb_scale` | `1.0` | **v4.01**：键盘缩放倍率，范围 `0.6`~`2.4`；拖右下角把手或托盘档位可改 |
| `kb_pos_x` / `kb_pos_y` | `null` | **v4.01 / v4.04 统一**：键盘左上角屏幕坐标；`null` = 沿用底部 / 居中。**v4.04 起两态共用**，不再只在「键帽可点」时生效 |
| `font_scale` | `1.0` | **v4.02**：键帽字体倍率，范围 `0.5`~`2.0`；`1.0` = v4.00 原始字号，与 `kb_scale` 相互独立；托盘档位或自定义窗口可改 |
| `delay_ms` | `0` | **v4.04 / v4.05**：按下辅助键到弹出的延迟毫秒数。`0` = 后台 1ms 异步弹出（默认，不阻塞按键）；v4.04 曾为同步弹出，v4.05 已修回异步。也可在托盘「弹出延迟」里选 150 / 300 / 500ms |

### 自定义指令（重点）

`config.json` 里的 `custom_shortcuts` 优先级最高，可以覆盖任意情境、任意组合、任意键：

```json
{
  "custom_shortcuts": {
    "Ctrl": {
      "C": "复制到飞书",
      "Q": "",
      "F8": "打开我的脚本"
    },
    "Ctrl+Shift": {
      "M": "发送会议纪要"
    }
  }
}
```

- 键名规则：字母 `A`~`Z`、数字 `1`~`0`、功能键 `F1`~`F12`、符号 `` ` - = [ ] \ ; ' , . / ``，特殊键 `TAB ENTER SPACE BACK DEL ESC HOME END PGUP PGDN LEFT RIGHT UP DOWN INS PRTSC CTRL SHIFT ALT WIN`
- 值填 `""` 可隐藏该键的指令（例如不想让 Ctrl+Q 亮起）
- 想增加应用情境：在 `shortcuts.py` 的 `APP_PROFILES` 里加一项 `{"name": "...", "exe": ["xxx.exe"], "tips": {...}}` 即可，无需改其他代码

## 七、技术与限制

- **零 GUI 框架依赖**：只用标准库 ctypes + Pillow。两个 `WS_EX_LAYERED | WS_EX_TOPMOST` 分层窗口，逐像素 alpha，均带 `WS_EX_NOACTIVATE` 不抢焦点。`WS_EX_TRANSPARENT` 只加在键盘主体上并由拨动开关动态增删；控件条窗口永远不加。
- 窗口以 `WS_POPUP` 创建：默认的 `WS_OVERLAPPED` 会带来 (8,31) 像素的非客户区偏移，让矮控件条上的点击变成 `WM_NC*` 消息收不到，也会让键帽命中整体偏移。鼠标坐标统一用「光标屏幕坐标 − 画面矩形」换算，与所见位置严格一致。
- 钩子默认**只观察不拦截**；唯一会主动产生输入的是「鼠标点击键帽」，通过 `SendInput` 注入一次完整的按下/抬起序列，并在 `dwExtraInfo` 里打上专属标记让低级钩子忽略，避免自激。点击不会记录或上传任何按键内容。
- 全局钩子在独立线程，主线程跑 Win32 消息循环，渲染有缓存，空闲时几乎不占 CPU。
- 不联网、不上传任何数据、不记录按键内容（只识别修饰键与组合键按下）。
- 按住 `Win` 时 Windows 自身会响应开始菜单，这是系统行为；松开后面板会正常收起。
- 部分软件以管理员权限运行时，普通权限进程的钩子仍能收到按键（只读钩子），不影响功能。
- 若某些全屏独占应用（游戏）使用 Raw Input，覆盖层仍会显示，但游戏内快捷键以游戏设置为准。
- 想打包成单文件 exe：`pip install pyinstaller && pyinstaller -w -i keyhint.ico --onefile app.py`（需把 `config.json` 与 `keyhint.ico` 一起放在 exe 旁）。

## 八、本地构建与版本管理

仓库不包含构建产物与历史快照，clone 后按下面步骤自行生成安装包：

```bash
pip install -r requirements.txt
pip install pyinstaller
python -m PyInstaller --noconfirm --distpath build/dist --workpath build/build installer/KeyHint.spec
python installer/build.py
```

- 两个 `.spec`（`KeyHint.spec` / `KeyHint_Setup.spec`）都使用相对路径，可在任意电脑、任意目录直接构建，不含本机用户名或绝对路径。
- `installer/build.py` 把 `build/dist/KeyHint` 打成 `payload.zip`，再生成单文件安装器、绿色版和 `SHA256.txt`，统一输出到 `安装包/`。
- 安装 / 卸载 / 快捷方式 / 自启动逻辑都在 `installer/setup_app.py`：只写用户目录与 `HKCU`，不需要管理员权限。
- 后续迭代按两位小数递增版本号（`4.07` → `4.08` …）；本地开发者可在改动前自行做同名完整快照备份（快照目录不入库）。
